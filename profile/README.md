# Hello there

I'm Alberth Matos. I build and maintain projects across software tools, 
experiments, research, automation, and other technical interests. I tend to
value breadth of experience and depth of knowledge over narrow specialization,
so you are likely to find a wide range of projects here.

Most repositories here are personal projects. Some are polished and maintained;
others are prototypes, notes, or work-in-progress explorations. Repository
READMEs should be treated as the source of truth for each project's status,
setup, and support expectations.

## Working Style

- Prefer clear, practical tools over heavy process.
- Keep project-specific conventions in the project that needs them.
- Use issues and pull requests for reproducible bugs, concrete improvements, and
  trackable maintenance work.

## Security

Please report suspected security issues privately. See `SECURITY.md` in the
relevant repository when available.
