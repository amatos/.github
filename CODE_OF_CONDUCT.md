# Code of Conduct

## Standard

Be respectful, constructive, and specific. Assume good faith, but do not use that
as a reason to ignore harm or disruptive behavior.

Unacceptable behavior includes harassment, personal attacks, discriminatory
language, threats, sustained off-topic disruption, or publishing someone else's
private information.

## Scope

This applies to project spaces including issues, pull requests, discussions,
code review, and other project-related communication.

## Enforcement

As the maintainer, I may edit, hide, or delete comments; lock threads; close
issues or pull requests; block users; or report abuse to GitHub when needed.

If you need to report a conduct concern, contact the maintainer privately when
possible. If the concern involves a security vulnerability, use the security
reporting process instead.
