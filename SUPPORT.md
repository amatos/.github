# Support

These are personal projects, not commercial support channels.

For help:

- Check the repository README.md and existing issues first.
- Open a GitHub issue when the problem is reproducible or likely to affect others.
- Use discussions when a repository has them enabled and the topic is exploratory.

Please include the project version, environment, relevant logs, and the smallest
reproduction you can provide.

Security issues should follow `SECURITY.md` instead of public support channels.
